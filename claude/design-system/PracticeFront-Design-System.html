Hover each card to preview the easing curve. Use Spring for UI interactions, Ease Out for entrances, Ease In-Out for state changes.

Buttons, cards, modals, dropdowns — any direct interaction
Ease Out
cubic-bezier(0.22, 1, 0.36, 1)
Page entrances, content reveals, elements entering the viewport
Ease In-Out
cubic-bezier(0.4, 0, 0.2, 1)
Theme switching, tab transitions, background state changes
