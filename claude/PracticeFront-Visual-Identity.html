Symbol Rationale

Three overlapping data blocks — each a layer of practice intelligence. The back layer (lightest) is raw, scattered data from the PMS. The middle layer is normalized, structured information. The front layer (boldest) is the clear, actionable insight. The progressive opacity tells the story of what PracticeFront does: it takes fragmented practice data and converges it into clarity. The stacking also maps to the Three Pillars — Patient, Scheduling, Collections — unified into one view.

02 — Color System
Three Directions
Each palette is designed with both dark and light variants. Toggle the theme above to see how each system adapts. All built for WCAG AA contrast compliance in both modes.

A — Indigo Trust Recommended

Cool indigo anchors trust and authority. Warm amber accent creates contrast without losing professionalism. The purple-to-indigo gradient adds premium depth.

B — Teal Vitality

Teal signals health and vitality without defaulting to generic "doctor blue." Rose accent is distinctive in dental tech. Feels energetic and modern.

C — Warm Authority

Breaks completely from healthcare blue. Amber and gold convey confidence and warmth. Sage green for health signals. The boldest, most disruptive direction.

05 — Motion Language
Choreography
Motion is communication, not decoration. Every animation answers: what changed, and where should I look? Spring physics over bezier curves. Stagger over simultaneous.

Entrance

Elements fade up with subtle Y translation

opacity: 0 → 1
translateY: 16px → 0
duration: 500ms
spring: { stiffness: 300, damping: 30 }

Stagger

Children animate sequentially, 60ms apart

staggerChildren: 0.06
delayChildren: 0.1
— Pillar cards: L → R
— Metrics: top → bottom

Hover / Lift

Cards lift on hover with shadow deepening

translateY: -2px

border-color: lighten
duration: 300ms ease-out

06 — Voice & Tone
How We Speak
PracticeFront sounds like a trusted advisor who respects your time. Direct, warm, confident — never condescending, never jargon-heavy, never vague.

Do This

"Your scheduling needs attention. No-show rate is 18% — industry average is 12%. Here are 2 partners who've helped similar practices."

Not This

"Your KPI analysis indicates a deviation in appointment completion metrics relative to peer benchmarks. Consider optimizing your recall workflow."

Do This

"Collections look great. You're in the top 20% of practices we track."

Not This

"Your net collection ratio of 96.4% places you at the 82nd percentile of our normalized practice cohort dataset."

Brand Voice Attributes
Direct

Say what you mean. "You have a problem" not "There may be an area of opportunity."

Warm

We're on your side. "Here's who can help" not "Please consult our partner directory."

Confident

We know this space. "This needs attention" not "You might want to consider looking into this."

08 — Implementation
Tech Specs
Built for Next.js 16 + React 19 + Tailwind CSS 4 + Framer Motion. Every token maps to a CSS custom property. Theme toggle uses data-theme attribute on <html>.
Theming Architecture
CSS Custom Properties on [data-theme="dark"] and [data-theme="light"]. All colors are semantic tokens (--bg-0, --accent, --success) that remap per theme. Components never reference raw color values — only tokens. Theme switch animates via 500ms CSS transitions.
Component Library
shadcn/ui as the base primitive layer, re-themed with PracticeFront tokens. Custom pillar cards, metric displays, and status indicators built on top. Radix UI for accessibility primitives.
Animation Stack
Framer Motion 11 for spring physics, layout animations, and scroll-triggered reveals. CSS transitions for micro-interactions and theme toggling. prefers-reduced-motion and prefers-color-scheme respected.
Typography Loading
next/font with variable font loading. Instrument Serif + Space Grotesk + Inter + JetBrains Mono. font-display: swap for performance. Fluid type using clamp() for display text.
